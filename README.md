# LA’VASH — шашлык & шаверма
LA’VASH — адаптивный сайт заведения общественного питания в Мурино.

Сайт разработан для удобного просмотра меню, фотографий блюд, цен и информации о заведении.

**Реализованные возможности:**
- Адаптивный интерфейс для компьютеров и смартфонов.
- Интерактивное меню с поиском и фильтрацией по категориям.
- Галерея фотографий с переключением и поддержкой свайпов.
- Контактная информация и быстрый звонок.
- Ссылки на Яндекс Карты и 2ГИС.

**Технологии:** HTML5, CSS3, JavaScript.

**Развёртывание:** GitHub + Vercel.
